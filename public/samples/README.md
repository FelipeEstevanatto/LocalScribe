# Sample audio

`jfk.wav` is an 11-second excerpt of President John F. Kennedy's inaugural address
(20 January 1961). It is a work of the U.S. federal government and is in the public
domain. The copy here comes from the `Xenova/transformers.js-docs` dataset on Hugging
Face, which uses it as a standard speech-recognition smoke-test clip.

It is bundled only so the app has a one-click demo; no network request is needed to
try the transcription pipeline.
